# homebrew-processmonitor

Homebrew tap for [Process Monitor](https://github.com/FagundesCristianoF/process-monitor) — a lightweight macOS menu bar app that monitors developer processes and auto-restarts them when memory limits are exceeded.

## Install

```bash
brew tap FagundesCristianoF/processmonitor
brew install --cask processmonitor
```

## Update

```bash
brew upgrade --cask processmonitor
```

## Uninstall

```bash
brew uninstall --cask processmonitor
```

## Requirements

- macOS 13 Ventura or later
